# 官方原声技能台词素材说明

> `public/audio/skill-voice/` 下 311 个 MP3 为**三国杀官方真人原声**技能台词，
> 覆盖 94 名武将、158 个技能，合计 18.6 MB，单条 1–5 秒。
> 台词文本见 [`src/audio/skillVoiceLines.json`](../../../src/audio/skillVoiceLines.json)。

## 来源

与阵亡台词同一条链路（见 [`../die-voice/素材说明.md`](../die-voice/素材说明.md)）：

- 台词目录与听写文本：<https://github.com/chenbenkong/sanguosha-cards> 的 `data/voice.json`
- 音频本体：三国杀官方 CDN `https://web.sanguosha.com/10/pc/res/assets/runtime/voice/skin/`
  （图鉴库自身**不含音频**，只有相对路径）
- 抓取脚本：[`tools/fetch-skill-voice.py`](../../../tools/fetch-skill-voice.py)（可重复执行，已存在的跳过）

## 目录结构与命名

```
public/audio/skill-voice/
  曹操/
    奸雄1.mp3      ← 序号从 1 开始
    奸雄2.mp3
    ...
```

序号对应 `skillVoiceLines.json` 里该武将该技能台词数组的下标 + 1：

```json
{ "曹操": { "奸雄": ["宁教我负天下人，休教天下人负我。", "…"] } }
```

一个技能通常有 1–6 句，运行时**随机取一句**，避免同一局里反复发动同一技能
时每次都听到完全一样的声音。

## 为什么按「武将 + 技能」两级查，而不是只按技能名

旧的 `SKILL_SLUG`（`src/audio/voice.ts`）是一张**全局**的技能名 → 文件名映射，
因为那批素材按技能名共享。官方原声不能这么做：

- 同名技能在不同武将手里的台词**并不相同**——实测 158 个技能条目对应 311 句，
  存在同名不同词的情况；
- 只按技能名做全局映射会把台词配错人。

所以官方原声走 `playOfficialSkillVoice(heroName, skillName)` 两级查表。

## 回退顺序

`showSkillBanner` 里两层，逐层降级：

1. `playOfficialSkillVoice(hero, skill)` —— 本目录的官方原声（94 名）
2. `playSkillVoice(skill)` —— 旧的 `audio/skill/`（71 条，含 TTS，全局共享）
3. 都没有就静音（不产生 404）

白名单由 `skillVoiceLines.json` 生成，未收录的武将/技能直接返回 `false` 且
**不发起请求**。

## 一个容易踩的坑：缺失文件不是 404

本项目是单页应用，`vite preview` 与 GitHub Pages 对未知路径都**回退到
index.html**，状态码 **200**、Content-Type `text/html`。`<audio>` 播放这种响应
会静默失败（`error.code === 4`），页面不报错、只是没声音。

`src/audio/skillVoice.test.ts` 因此做了四道守卫：表里每条都有文件、目录里没有
孤儿文件、内容确实是 MP3（不是 HTML）、技能名不含路径分隔符（否则拼出的路径会
跑出武将目录）。

## 覆盖缺口（5 名）

图鉴库无这些武将的语音条目：蔡贞姬、张瑾云、庞凤衣、杨婉，以及写法差异的
马云禄（图鉴库作「马云**騄**」，脚本里用 `NAME_ALIASES` 显式映射，**不做模糊
匹配**——模糊匹配会把不同武将的台词配错）。

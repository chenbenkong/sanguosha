# 官方原声阵亡台词素材说明

> 本目录（`public/audio/die-voice/`）的 123 个 `<武将中文名>.mp3` 为**三国杀官方真人原声**
> 阵亡台词，每支 1.1–8.9 秒、单声道 MP3，合计 4.4 MB（123 条中 106 条为 64kbps）。
> 台词文本见 [`src/audio/dieVoiceLines.json`](../../../src/audio/dieVoiceLines.json)。

## 码率与体积（入库版已转码）

官方 CDN 给的是原始码率文件（实测约 128~192kbps 单声道），而每条只是 1~9 秒的台词。
入库的是**转码版**：

```
# 需要 ffmpeg；本仓库不把它列为依赖，转码是一次性的
ffmpeg -hide_banner -loglevel error -y -i <原始文件> \
       -ac 1 -ar 44100 -b:a 64k -map_metadata 0 -id3v2_version 3 <输出文件>
```

| | 原始 | 转码后（当前入库） |
| --- | --- | --- |
| 单文件 | 约 128~192kbps | 64kbps 单声道为主（106/123 条；其余 17 条为 56/80/96/112/128kbps） |
| 合计 | 6.8 MB | **4.4 MB** |

码率分布是 `ffprobe` 之外用帧头实测的：56kbps ×2、64kbps ×106、80kbps ×2、
96kbps ×1、112kbps ×8、128kbps ×4；时长 1.07–8.86 秒，合计 9.0 分钟。

验证：全部文件用 ffmpeg 完整解码一遍（`-f null -`）无告警，排除截断；
抽样在真实浏览器里读时长并与转码前对比，最大偏差 0.1%。

## 与旧语音目录的区别

| | `audio/die/`（旧） | `audio/die-voice/`（本目录） |
| --- | --- | --- |
| 命名 | 武将 id（拼音），如 `sunshangxiang.mp3` | 武将中文名，如 `孙尚香.mp3` |
| 覆盖 | 45 名 | **123 名** |
| 来源 | 24 条 noname 社区素材 + 21 条 TTS 合成 | **全部官方真人原声** |
| 音质 | 混合 | 64kbps 单声道为主（见上「码率与体积」） |

命名改为中文名是刻意的：它和 `public/images/heroes/<中文名>.webp` 同源，
引擎侧拿 `hero.name` 就能拼路径，不必再维护「id → 拼音」的映射表。

## 回退顺序

`src/audio/voice.ts` 中阵亡语音有三层，逐层回退：

1. `playOfficialDeathVoice(hero.name)` —— 本目录的官方原声（123 名）
2. `playDeathVoice(hero.id)` —— 旧目录 `audio/die/`（45 名，含 TTS）
3. `playSound('death')` —— 合成提示音（无人声）

白名单 `DEATH_VOICE_LINES`（由 `dieVoiceLines.json` 生成）只登记**文件确实存在**的条目，
未收录的武将直接返回 `false`，不会发起请求，因此不会产生 404。

以 `constants.ts` 的 `HEROES`（129 名）为准，本目录覆盖 123 名，缺 6 名：

| 武将 | 原因 |
| --- | --- |
| 蔡贞姬 | 图鉴库无此条目（本项目独有武将） |
| 张瑾云 | 图鉴库无此条目的阵亡语音 |
| 甘宁 / 步练师 / 许褚 / 华佗 | 图鉴库无这几名的官方阵亡语音，退回旧目录 `audio/die/` |

马云禄（图鉴库作「马云**騄**」）已由脚本的 `NAME_ALIASES` 显式映射补齐，
**不做模糊匹配**——模糊匹配会把不同武将的台词配错。

## 一个容易踩的坑：缺失文件不是 404

本项目是单页应用，`vite preview` 与 GitHub Pages 对未知路径都**回退到 index.html**，
状态码是 **200**，Content-Type 是 `text/html`。也就是说：

- 光看「HTTP 200」会以为文件在，实际拿到的是首页 HTML
- `<audio>` 播放这种响应会静默失败（`error.code === 4`），页面不报错、只是没声音

真实 MP3 返回的是 `Content-Type: audio/mpeg`，前几字节为 `ID3` 或 `0xFF` 帧同步。
`src/audio/dieVoice.test.ts` 用这条特征做了两道守卫：文件存在、以及内容不是 HTML。

## 关于「不再新增配音」旧约定的变更

`public/audio/语音说明.md` 曾写明「2026-11 收尾验收起不再为新增武将生成台词配音、不下载第三方语音包」。
该约定的背景是当时找不到可用的官方语音包，只能靠 TTS 合成。

本次应用户明确授权（「资源随便用」）改为直接引用官方真人原声，因此：

- 只为**阵亡**这一档接入（93→123 条；技能台词走 `audio/skill-voice/`，见该目录说明）
- 不做任何音色模仿，不生成台词文本，全部是官方音频原样引用
- 旧目录 `audio/die/` 保持原样不删除，作为第 2 层回退
